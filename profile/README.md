# Stew GitHub Organization

![stew_hero_image](https://github.com/RobloxStew/.github/assets/stew-hero.png)

This is the Stew GitHub Organization, where we build open-source tools and services for creating Roblox experiences. Help us bring the Studio experience to more platforms by submitting suggestions, fixes, ideas, and contributions.

### Get Involved

We welcome contributors, creators, and developers to help build Stew and its surrounding projects.

* Explore [Stew](https://github.com/RobloxStew/Android), our Android Studio-inspired development environment.
* Explore our other [open source projects](https://github.com/orgs/RobloxStew/repositories).
* Report bugs, suggest features, or contribute improvements through GitHub.
* Share ideas and feedback with the Stew community.

### Our Projects

* **Stew for Android** — A Roblox Studio-inspired development environment built for Android.
* **Stew Backend** — The backend services that connect Stew with Roblox services.
* **More coming soon** — Additional tools and services are planned as Stew grows.

### Our Goal

Stew is built around one idea: **make creating experiences more accessible.**

We're working to bring the core Roblox Studio workflow to devices beyond the traditional desktop environment, while keeping Stew focused on building, editing, testing, and publishing experiences.

The world is ours for the making. Let's build it.
